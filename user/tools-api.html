Example Code

PHP (cURL)

$api_url = file_get_contents("API-ENDPOINT?api=YOUR_KEY&url=" . urlencode($long_url));
$data = json_decode($api_url, TRUE);
echo $data["shortened"];

JavaScript (fetch)

const res = await fetch("API-ENDPOINT?api=YOUR_KEY&url=" +
                         encodeURIComponent("https://example.com"));
const data = await res.json();
console.log(data.shortened);
