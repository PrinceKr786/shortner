Kaise Use Kare?

1 Upar ka "Shortify It!" button ko apne browser ke Bookmarks Bar me drag & drop karo.
2 Jab kisi bhi website pe ho aur short link chahiye, to bookmarks bar pe "Shortify It!" pe click karo.
3 Ek popup khulega jisme current page URL hoga. Apna custom alias dalo ya khali chhodo (auto generate hoga).
4 "Shorten" button dabao. Short link turant ready! Copy karke use kar sakte ho.

Tip

Bookmarklet tab kaam karega jab aap Shortify pe logged in ho. Agar nahi ho to pehle login karo.
